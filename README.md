# Money — แอพจัดการการเงินส่วนตัว 💰

แอพบันทึกรายรับ-รายจ่ายส่วนตัว สร้างด้วย React Native + Expo (Managed Workflow) —
**ไม่มี backend ไม่ต้อง login** ข้อมูลทั้งหมดเก็บใน SQLite บนเครื่องของคุณเท่านั้น

## ฟีเจอร์

- **Dashboard** — ยอดรวมทุกบัญชี สรุปรายรับ/รายจ่าย/คงเหลือของเดือน กราฟรายจ่าย 7 วันล่าสุด และรายการล่าสุด
- **บันทึกรายการ** — รายจ่าย / รายรับ / โอนระหว่างบัญชี พร้อมแนบรูปสลิป เลือกวันที่ย้อนหลังได้
- **ประวัติรายการ** — ค้นหา กรองตามประเภท/บัญชี/หมวดหมู่ จัดกลุ่มตามวัน swipe เพื่อแก้ไข/ลบ (ลบแล้วคืนยอดกลับบัญชีอัตโนมัติ)
- **บัญชี** — เงินสด / ธนาคาร / บัตรเครดิต / e-Wallet, ลบบัญชีได้โดยย้ายหรือลบรายการที่ผูกอยู่ก่อน
- **หมวดหมู่** — หมวดเริ่มต้นภาษาไทยครบชุด เพิ่ม/แก้ไข/ซ่อน เลือกไอคอนและสีเอง (หมวดเริ่มต้นซ่อนได้แต่ลบไม่ได้)
- **รายงาน** — donut chart ตามหมวด, กราฟรายรับ-รายจ่ายรายเดือน, เลื่อนดูรายสัปดาห์/เดือน/ปี (โอนเงินไม่ถูกนับ)
- **จัดการหนี้** — ติดตามการผ่อน ดอกเบี้ยแบบง่ายต่อปี ไทม์ไลน์ทุกงวด (✅ จ่ายแล้ว / ⏳ ยังไม่ถึง / ❌ ค้างจ่าย) ปุ่ม "จ่ายงวดนี้แล้ว" สร้างรายการจ่ายอัตโนมัติ
- **งบประมาณ** — วงเงินต่อหมวดต่อเดือน สถานะเขียว/เหลือง/แดง แจ้งเตือนที่ 80% และ 100% คัดลอกงบจากเดือนก่อนได้ คำนวณตามวันเริ่มต้นเดือนที่ตั้งไว้
- **รายการประจำ** — รายสัปดาห์/รายเดือน สร้าง transaction ให้อัตโนมัติเมื่อเปิดแอพและถึงกำหนด
- **แจ้งเตือน** — เตือนบันทึกประจำวัน (ตั้งเวลาได้), งบใกล้หมด/เกิน, หนี้ใกล้ครบกำหนด (ตั้งจำนวนวันล่วงหน้าได้), รายการประจำล่วงหน้า 1 วัน
- **ตั้งค่า** — ธีมสว่าง/มืด/ตามระบบ, สกุลเงิน, วันเริ่มต้นเดือน (เช่น 25 ตามรอบเงินเดือน), ส่งออก/นำเข้า CSV, ล้างข้อมูลทั้งหมด (ยืนยัน 2 ชั้น)

## Tech Stack

| ส่วน | เทคโนโลยี |
| --- | --- |
| Framework | React Native + Expo SDK 53 (Managed) |
| ภาษา | TypeScript (strict) |
| Navigation | React Navigation 7 (Bottom Tabs + Native Stack) |
| State | Zustand |
| ฐานข้อมูล | expo-sqlite (WAL mode + indexes) |
| กราฟ | react-native-chart-kit + custom bar charts |
| ไอคอน | phosphor-react-native |
| วันที่ | @react-native-community/datetimepicker |
| รูปภาพ | expo-image-picker |
| แจ้งเตือน | expo-notifications (local only) |

## เริ่มต้นใช้งาน

```bash

npm run android    # หรือรันบน Android
npm run ios        # หรือรันบน iOS

```

## โครงสร้างโปรเจกต์

```
src/
├── components/    # UI ที่ใช้ร่วมกัน (Card, ProgressBar, ChoiceModal, ...)
├── constants/     # หมวดหมู่เริ่มต้น, icon registry, color palette
├── db/            # ชั้น SQLite: schema + repository ต่อตาราง
├── navigation/    # RootNavigator (Tabs + Stack) และ param types
├── screens/       # หน้าจอทั้งหมด 17 หน้า
├── services/      # business logic: balance, recurring, budget alerts, CSV, notifications
├── store/         # Zustand stores
├── theme/         # design tokens (สี light/dark, spacing, radius)
├── types/         # data models
└── utils/         # format เงิน ฿1,234.56 / วันที่ไทย พ.ศ. / ช่วงเดือน / คำนวณหนี้
```

## หมายเหตุเรื่องการสแกนสลิป (OCR)

แอพนี้ไม่มี backend จึงยังไม่ได้ต่อ OCR จริง — ปุ่มสแกนสลิปจะแนบรูปเข้ารายการและให้ผู้ใช้กรอกจำนวนเงิน/วันที่เอง
จุดต่อขยายอยู่ที่ `src/services/receiptScanService.ts` (`scanReceipt`) — สามารถเสียบ vision model
(เช่น Claude API) เพื่อดึงจำนวนเงินและวันที่จากรูปได้ทันที

## Logic สำคัญ

- ลบรายการ → คืนยอดกลับบัญชี, แก้ไขรายการ → ย้อนยอดเก่าแล้วบวกยอดใหม่ (`src/services/transactionService.ts`)
- โอนเงินไม่ถูกนับเป็นรายรับ/รายจ่ายในรายงานและสรุปเดือน
- เดือนงบประมาณเริ่มตาม `monthStartDay` (default 1, ตั้งเป็น 25 ตามรอบเงินเดือนได้)
- หนี้: ดอกเบี้ยแบบ simple interest ต่อปีตามสูตรใน spec, progress bar ไล่สีเขียว→เหลือง→แดง
- แสดงเงินรูปแบบ `฿12,500.00` (Intl.NumberFormat) และวันที่ไทยปี พ.ศ. เช่น `29 มิ.ย. 2569`
